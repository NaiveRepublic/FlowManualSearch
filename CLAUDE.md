# Flow Manual Search: notes for Claude Code

Offline Windows desktop app that answers questions by pointing to sections and pages of the Dirac Flow 5.6 user manual. The README explains it for end users; this file is the working brief.

## Hard constraints

- **The finished app must never access the internet.** No network calls at runtime, no CDN assets, no fonts from the web, no telemetry. The fallback server binds to 127.0.0.1 only.
- Target: single-file `dist\FlowManualSearch.exe`, Windows 11+, x64, built with Python 3.12.
- Keep the pinned versions in `requirements-*.txt` unless a build fails because of one of them.

## Layout

- `app/main.py`: entry point. Native window via pywebview (Edge WebView2); falls back to Edge `--app` mode with a loopback HTTP server. Flags: `--selftest` (one search, prints JSON, exits), `--server` (force fallback).
- `app/search_engine.py`: `ManualIndex`: hybrid ranking = 0.55 × semantic (WordLlama static embeddings, mean-pooled, cosine) + 0.45 × BM25 with title boost and synonym expansion. Results below 0.2 are treated as no match.
- `app/ui/index.html`: self-contained UI (inline CSS/JS, system fonts Bahnschrift + Segoe UI). Calls `window.pywebview.api.*`, or `/api/*` when opened with `?mode=server`.
- `app/data/`: generated by `build_tools/build_index.py`. Do not edit by hand.
- `FlowManualSearch.spec`: PyInstaller recipe (one-file, windowed, no UPX).

## Build and test on Windows

```bat
build.bat
```

Or step by step:

```bat
py -3.12 -m venv .venv
.venv\Scripts\python -m pip install -r requirements-app.txt
.venv\Scripts\python app\main.py --selftest
.venv\Scripts\python -m PyInstaller --noconfirm --clean FlowManualSearch.spec
dist\FlowManualSearch.exe
```

After building, launch the exe and confirm: the window opens; a search for "How do I connect Flow to the device?" lists 8.2 first; **Show on page** shows page 17 with the heading marked; **Open PDF at page** opens Edge at that page. Also run `dist\FlowManualSearch.exe --selftest` from a console.

## Rebuilding the index for a new manual

```bat
.venv\Scripts\python -m pip install -r requirements-index.txt
.venv\Scripts\python build_tools\build_index.py "path\to\manual.pdf"
.venv\Scripts\python build_tools\eval_queries.py
```

The WordLlama model files ship inside the `wordllama` pip package; `build_index.py` loads them directly from the package folder and never calls the library's downloader.

Last measured on the 5.6 manual: top-3 25/25, top-1 22/25, about 0.6 ms per query.

## Known quirk in the 5.6 manual

Section 5.3.1 (page 10) is titled "Lock for editing" and repeats the text of 5.3.10 (page 11). The index reflects the manual as published.
